# Office-Link v1.0.0 릴리스 노트

릴리스 날짜: 2026-08-05

## 릴리스 개요

Office-Link v1.0.0은 분산된 사내 업무와 규정 검색을 하나의 대화형 화면으로 통합한 최종 발표 버전입니다. 조회·추천은 AI Agent와 MCP가 처리하고, 생성·수정·취소는 구조화된 Action Draft에서 사용자가 확인한 값만 Final Backend가 실행합니다.

## 주요 하이라이트

- 회의실 예약, 방문객 주차 등록, 사무용품 신청의 조회·수정·취소 UI
- 필수값 기본 설정과 조건 기반 추천을 제공하는 빠른 실행
- 부서·역할 권한을 보존하는 사내 규정 RAG
- Vector 0.6 / Keyword 0.4 Hybrid Search와 BGE v2-m3 OpenVINO FP32 Re-ranking
- 위험 신호가 있는 답변만 코드·LLM으로 검증하는 선택적 Self-Correction
- Azure SSO, JWT, OAuth2 Client Credentials, Scope, JWKS 기반 인증
- 메모리 배치와 Kafka를 이용한 관측 로그 적재
- 온프레미스 Gemma와 OpenAI 호환 모델을 교체 가능한 LLM 설정

## 배포 구성

- 5개 애플리케이션과 PostgreSQL 2개, Redis 3개, Kafka를 Docker Compose로 실행
- Frontend Nginx를 단일 진입점으로 사용
- PostgreSQL, Redis, Kafka, Re-ranker 모델은 Docker volume에 유지
- 발표 노트북과 GPU 서버는 고정 IP 유선 네트워크로 연결

## 검증

- Final Backend와 Workhub Backend: JUnit + JaCoCo
- AI Agent와 MCP Server: pytest + pytest-cov
- Frontend: Node test + Vite production build
- Agent: 개발용·최종 평가용 데이터셋 기반 Tool 계약과 LLM-as-a-Judge 평가
- RAG: 300개 평가 질문 기반 검색 조합, 임계값, Re-ranker, 실행 엔진 비교

## 알려진 제약

- 온프레미스 모델 사용 시 GPU 서버와 유선 네트워크가 준비되어 있어야 합니다.
- Re-ranker 캐시가 없는 최초 실행은 모델 준비 때문에 오래 걸릴 수 있습니다.
- Azure 로그인은 등록된 Redirect URI와 Tenant 정책에 의존합니다.
- Kafka UI는 기본 실행에서 제외되며 `-WithOps` 옵션으로 활성화합니다.
- 실서비스 배포 시 HTTPS, 운영 Secret 저장소, 외부 모니터링과 백업 정책을 별도로 구성해야 합니다.

## 업그레이드와 데이터

이 릴리스는 Flyway로 DB 스키마를 관리합니다. `stop.ps1`과 `start.ps1`로 재배포하면 기존 Docker volume을 재사용하며, volume을 명시적으로 삭제하지 않는 한 데이터는 유지됩니다.

## 최종 실행 체크리스트

1. `deploy/.env`의 필수 Secret과 외부 API 주소 확인
2. `.\deploy\start.ps1 -ValidateOnly` 통과 확인
3. GPU 서버 `/v1/models`, OpenAI Embedding API, Azure Redirect URI 확인
4. `.\deploy\start.ps1 -WithOps` 실행 후 전체 컨테이너 health 확인
5. 로그인, SSE 채팅, Action Draft, RAG, 로그 적재 시나리오 점검
6. `.\deploy\coverage.ps1`과 Agent 하네스 최종 결과 보관
